# Glossário

Volta para: [[Início]] · [[Método IRA]]

| Termo | Significado |
|---|---|
| Berçário | Unidade com até 120 dias de operação, contados da inauguração real |
| Fomento | Dias 121 a 150. Mesma meta e prêmio do berçário |
| Marco do berçário | R$ 3.000 por mês, mantendo ou crescendo |
| Mínimo regular | R$ 4.700 de faturamento no mês |
| Status | Saudável, Atenção, Recuperação, Crítico, pelo faturamento. Ver [[Método IRA#1. Status da unidade]] |
| Royalties | 15% do faturamento bruto + R$ 300 de taxa de sistema |
| Borda de faixa | Unidade a até R$ 500 de faturamento da próxima faixa de royalties |
| Renovação | Cliente continua com o mesmo item |
| Retenção | Cliente ativo troca de item ou aluga mais um |
| Reativação | Cliente antigo volta a alugar |
| Item e Cobrança | Tipos de registro no relatório de vendas do Gestão. Não somar sem separar |
| Gestão | Sistema da rede: pedidos, faturamento, Campanhas, Giro Inteligente |
| Giro Inteligente | Recurso do Gestão para girar estoque |
| CKA | Loja própria de João Pessoa |
| clubkids+ | Frentes de João Pessoa: Cuidar de Mim (CUIDARE), Crescer Brincando, Economizar, Alimentar Bem |
| D-3 e D-1 | Confirmação da reunião 3 dias antes e briefing 1 dia antes |
| Método IRA | Inteligência, Relacionamento, Aceleração. Ver [[Método IRA]] |
