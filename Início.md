# Íris | Supervisão IRA o clubkids

Cofre da Supervisão Nacional de Franquias. Começar por aqui.

**Objetivo:** todas as unidades faturando bem. Se a unidade fatura bem, todos ganham.

## Todo dia
- [[Tarefas]]: o que está aberto, por unidade
- [[Diário]]: o que foi feito em cada dia
- [[Rotinas]]: resumo das 9h, fechamento das 18h, decisões de sexta

## Rede
- [[Unidades]]: as 121 unidades, por fase (berçário, fomento, regular)
- [[Painel de Unidades.base|Painel de Unidades]]: tabela com filtros

## Como usar o cofre
- Captura rápida vai para `00 Entrada`. Depois, mover para a pasta certa.
- Nota nova sempre com link para uma unidade, um mapa ou esta página.
- Modelos em `80 Modelos`: [[Modelo Unidade]], [[Modelo Reunião]], [[Modelo Diário]].
- Dados brutos de clientes, CPF e telefones não entram no cofre.
